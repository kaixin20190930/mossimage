# mossimage.run 完整产品实施方案

## 一、产品定位与核心策略

**定位**：MOSS-Image 在线生成器。给用户一个零门槛的入口，输入 prompt 就能出图——然后围绕这个生成器，用内页矩阵把所有长尾搜索需求全部接住。

**核心依据**（来自本轮实测）：

- **首页主词 `moss image generator`，哥飞版难度 18.8 分（极易），前十全是内页，无人用首页经营。** 这是哥飞在 4 群说过的标准切入点——"任何一个词，只要目前谷歌搜索前五没有首页，就可以做一个网站去竞争"（2024-05-12，回应罐头）。你这个词更夸张：**前十都没有首页**。

- **MOSS-Image** 是 Apache 2.0 开源的 50 亿参数扩散模型，10 月 16 日发布（仅过去 5 天），支持 JSON 布局控制 + 中英文文字渲染，原生集成 ComfyUI。所有长尾词都在规划师真空期里——**现在上站就是抢窗口**。

- **fal.ai API** 已经封装好了 MOSS-Image-SFT 版（强化了文字渲染和布局精度），定价 `$0.05/megapixel`，支持商用。

**一句话策略**：首页做生成器（打 `moss image generator`，KD 18.8），内页矩阵覆盖全部有价值的长尾词，两周内铺完所有页面。

**内链规则**（哥飞在《从网站站内优化到部署上线》讲的原话）：

**为什么必须这样排**：工具站首页最大的劣势是内容薄，而 MOSS-Image 这个词本身还是熊掌未定的新词，谷歌需要足够信号才敢给排名。首屏以下 600~900 字 + 两层内链，是让谷歌确认“这是个有主题的站，不是空壳工具页”的最低配置。社群里的复盘也说得很直白（孙掌柜，2026-03-09，2 月新词新站复盘）：**上线快不等于跳过 SEO 审查，“上线之前都还是会对 seo 相关的内容进行审查、调整”**。

另外按哥飞《从 TDK 到 TDH》的口径，**`<meta name="keywords">` 不用写**——这个标签早就被淘汰了。真正要写的是 Title、Description、Headings 三件套。

已按你的 10 个页面写好一份完整对照表，沉淀在「⋯ → 沉淀与记忆 → `mossimage.run 全站 TDK 对照表`」里，可以直接下载 CSV。这里给三条必须遵守的规矩和首页样例：

| 元素 | 规矩 | 首页样例 |
|---|---|---|
| **Title** | 主词放最前，60 字符内，不加 `keywords` 标签 | `MOSS-Image Generator — Free Online AI Image Tool with JSON Layout Control` |
| **Description** | 155 字符内，说清“是什么 + 免费 + 差异点” | `Generate images with MOSS-Image, the 5B open-source diffusion model with JSON layout control. Free online, no install, supports Chinese and English text.` |
| **H1** | **只含一个主词**，和 Title 主词一致，不塞第二个词 | `MOSS-Image Generator` |

三条最容易犯的错：

1. **H1 别塞两个词。** 把 `moss image generator` 和 `moss image ai` 都写进 H1，等于让谷歌猜你要做哪个。`moss image ai` 作为 Title 里的并行修饰（`AI Image Tool`）已经覆盖了，不需要单开页面。
2. **Description 不要复制 Title。** 谷歌会自己截取，重复写等于浪费一次给用户看“为什么要点你”的机会。
3. **内页 Title 主词必须独占。** `/comfyui/` 的 Title 里有 `ComfyUI` 和 `Workflow JSON Download` 两个卖点是对的，但 `moss image comfyui` 这个完整词组必须原样出现在最前面。

## 四、生成功能：技术方案与成本闸门

这是你这次唯一的真金白银成本，必须先把账算清。

### 4.1 调用链

```
用户输入 prompt
   ↓
前端（/ 首页）
   ↓
你的后端（限流 + 额度校验 + 日志）
   ↓
fal.ai  →  fal-ai/moss-image  →  $0.05 / megapixel
   ↓
返回图片 URL → 前端展示 + 下载
```

**用 fal.ai 起步，不要自己部署。** 理由：MOSS-Image 是 50 亿参数扩散模型，自部署需要 GPU 常驻，成本是固定的、与用量无关；而你现在连真实搜索量都测不出来（全部长尾词在规划师真空期），**用多少付多少的按量计费才配得上这种不确定性**。等日均出图量稳定超过那个盈亏平衡点，再谈自建。

### 4.2 单价换算成实际成本

`$0.05/megapixel` 意味着成本跟图片尺寸直接挂钩。按常见出图规格折算：

| 尺寸 | 像素数 | 单张成本 |
|---|---|---|
| 512×512 | 0.26 MP | ≈ $0.013 |
| 768×768 | 0.59 MP | ≈ $0.030 |
| 1024×1024 | 1.05 MP | ≈ $0.052 |
| 1024×1536 | 1.57 MP | ≈ $0.079 |

**这是按像素线性折算的估算，不是 fal.ai 的官方档位——实际计费以你后台账单为准。** 但量级足够你做决策：**每张图 1~8 美分**。

### 4.3 免费额度必须卡死

这是整套方案里最容易亏钱的地方。按哥飞在 2026-05-15 群聊总结里的口径：**用免费额度换流量、让付费用户覆盖成本**，是这类站可行的商业模式，但前提是免费额度不能被人刷穿。

建议参数：

| 项 | 建议值 | 为什么 |
|---|---|---|
| 未登录每日免费 | **3 张** | 3 张够用户体验完整产品，成本上限 3×$0.052 ≈ $0.16/人/天 |
| 登录后每日免费 | **10 张** | 用邮箱/Google 登录换额度，同时沉淀用户资产 |
| 单 IP 频率 | 1 张 / 30 秒 | 挡住脚本并发 |
| 超出额度 | 看广告解锁 1 张 **或** 付费 | 两条路都要有，广告是零门槛那条 |
| 高风险地区 | 免费额度直接关闭 | 社群共识做法，见下文 |

**社群里的原话**：安徒生在 5 群（2025-01-27）说自己直接屏蔽印度和俄罗斯的免费额度，另一位成员回应“都快成为共识了”——这两个地区的用户不转化、纯烧 API。这不是地域偏见，是成本控制：**免费额度是营销预算，要花在可能付费的人身上。**

### 4.4 变现顺序

**先广告，后订阅。** 哥飞在 2025-06-25 的 3 群聊过他自己 AI 工具站的实情（原话大意）：免费额度给得比较多、用户付费不多，结果 **AdSense 反而成了收入大头**，好在 AI 成本不高，整体还算能跑。

对你这个站的意思很明确：
- **第 1~2 周**：只上 AdSense 申请 + 免费额度，不做付费
- **有稳定流量后**：再加 “Pro 版”（提高额度、去掉水印、更快出图、JSON 布局高级控制）
- **不要一上线就挂订阅墙**——新词站用户还没建立信任，付费墙只会压死转化率

## 六、四个必须认的风险

1. **这是一次性热点，不是长期饭票。** MOSS-Image 10 月 16 日发布，10 月 18 日热度冲到 100，今天是第 5 天。参考 25 年年度比赛第 8 名（泛文）的复盘：这类新词站典型结局是抓一波量就掉。**赚一波，别当归宿。**

2. **官方可能自己做生成器。** openmoss.ai 现在 DR 36、月流量 1.3 万，看起来还没在 SEO 上认真投入。一旦他们上线官方在线生成器，你首页那 18.8 分的优势会被直接抹平。**这是必须抢时间的唯一理由。**

3. **成本会随流量线性上涨，收入不会。** 每多 1000 次免费生成就是 $13~52 的硬支出（按上表折算），而 AdSense 的千次展示收入远低于这个数。**免费额度是你唯一的刹车，参数必须在上线第一天就设死。**

4. **`moss image` 裸词（1600/月）不要碰。** 它的 SERP 是 Adobe Stock、Unsplash、Pinterest 这些苔藓图片站，谷歌把“moss”理解成苔藓，意图完全不匹配。你的首页主词只能是 `moss image generator`。
